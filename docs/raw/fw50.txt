Firmware v50 features: USB MIDI input and output functionality has been added, bug fixes (resolved issues with the arpeggiator and sequencer not resetting
properly, fixed the problem with non 1V/octave modes not loading properly on modules with Teensy 4.0, addressed the uncontrolled pitch shifting when exiting the
note sequence recorder), live functions have been removed (as they were confusing for some users), improved internal clock algorithm (clock now has a dedicated
page in the settings menu, eliminating the need for button combinations), enhanced pressure information acquisition (previously only the last active plate was
scanned, but now all keys are scanned simultaneously).

                            SENSITIVITY, DEBOUNCE, ENCODER DIRECTION, VREF
       To adjust these attributes, press and hold the encoder during power-on. Rotate it to scroll through the parameters. Click the encoder to enable/disable editing of values. After setting these
        values, the module needs to be rebooted by turning off and then on your system. The reason why these parameters are not easily accessible is that they typically require adjustment only
                                                                         once during the initial setup of a freshly built module.

                                                                                      DEBOUNCE AND SENSITIVITY
         Some MPR121 breakout boards may behave differently regarding the sensitivity of touch plates. If your module in keyboard mode (with disabled arpeggiator and sequencer) behaves
       unpredictably, as if it’s a sequencer clocked by a Geiger counter, try increasing DEBOUNCE and/or lowering SENSITIVITY. The best practice is to keep SENSITIVITY as high as possible and
                                                                                       DEBOUNCE as low as possible.

                                                                                         ENCODER DIRECTION
                                                            Determines the direction of encoder rotation. It has two states: normal or reversed.

                                                                                                  VREF
      The fourth parameter enables/disables the internal voltage reference of the DAC (digital-to-analog converter). Set VREF to IN if using DAC8562 or DAC8563, set VREF to EX if using AD5663.
                                   Note that this parameter only has an effect on modules built with Teensy 4.0; on modules with Teensy 3.2, it won’t even appear.
